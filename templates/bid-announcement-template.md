# 입찰 공고문 표준 템플릿

특정 업체에 유리한 조건이 들어가지 않도록, 아래 항목을 빠짐없이 채워서 공개합니다.
`[대괄호]`는 실제 값으로 교체하세요.

## 1. 사업 개요

- 사업명: [예: 202X년도 단지 승강기 유지보수 용역]
- 사업 목적/범위: [구체적인 작업 범위를 서술]
- 계약 기간: [예: 1년, 자동 갱신 여부 명시]
- 단지 규모: [세대수, 동수 등 견적 산출에 필요한 정보]

## 2. 입찰 참가 자격

- [ ] 관련 법령상 요구되는 등록/면허/보험 요건 (구체적으로 명시)
- [ ] 최근 N년 이내 동종 업무 수행 실적 (특정 업체만 충족 가능한 과도한 실적 요건 금지)
- [ ] 특정 브랜드·제조사·모델명을 자격 요건으로 지정하지 않음 (동등 이상 제품/규격으로 명시)

## 3. 평가 기준 (사전 공개, 배점 합계 100점)

| 평가 항목 | 배점 | 세부 기준 |
|---|---|---|
| 가격 | [ ]점 | |
| 기술/수행능력 | [ ]점 | |
| 실적/신뢰도 | [ ]점 | |
| 기타 | [ ]점 | |
| **합계** | **100점** | |

## 4. 일정

- 공고일: [YYYY-MM-DD]
- 입찰 마감일: [YYYY-MM-DD] (공고일로부터 최소 10일 이상 권장 — 특정 업체만 사전 준비할 시간을 갖지 않도록)
- 개찰/결과 발표일: [YYYY-MM-DD]

## 5. 유의 사항

- 특정 업체에 유리하거나 불리한 조건을 포함하지 않습니다.
- 모든 입찰 참가자에게 동일한 정보를 동일한 시점에 제공합니다.
- 낙찰 결과와 평가 근거(배점표별 점수)는 입찰 참가자와 주민에게 공개합니다.
